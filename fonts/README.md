# Yaho Sans

`YahoSans-Variable.woff2`는 Pretendard JP Variable(© Kil Hyung-jin, SIL Open Font License 1.1)에서
앱에 필요한 글자(영문, 한글 상용 2,350자, 가나, 일본 상용 한자 JIS 제1수준 2,965자, 앱에 쓰인 글자)만 남기고
굵기 범위를 400–900으로 줄인 수정본임. OFL 규칙상 수정본은 원래 이름(Reserved Font Name "Pretendard JP")을 쓸 수 없어서
이름을 "Yaho Sans"로 바꿨음. 라이선스 전문은 OFL-Pretendard.txt.

이 글꼴에 없는 글자(드문 한글·한자)는 폰의 기본 글꼴로 보임.
